# InkRoam
Project Profile
Sanyuan-World is a training, testing, and ablation framework that adapts Tencent HY-World 2.0 to Chinese landscape paintings for 3D world generation. It freezes the official weights of three components — HY-Pano 2.0 for panorama generation, WorldStereo 2.0 for memory expansion, and WorldMirror + gsplat for 3D reconstruction — and introduces three targeted modifications: hierarchical text conditioning, Three-Distance camera trajectories, and LOP-based quality gating. No diffusion backbone is trained. In this project, “training” means rerunning the frozen generation pipeline from the stage affected by a modification; the cost is determined by the rerun start point, not by the number of training epochs.
The painting corpus is derived from the 6,511 input images shipped with HY-World 2.0. After auditing, 1,491 images are usable. The main evaluation table uses 15 paintings stratified into 5 composition categories with 3 paintings each, while internal ablations are performed on a 3-painting core subset. The experimental environment is 4× NVIDIA H20; the full ablation consumes about 700 GPU·h and takes about 6 days with 4-card parallelism.
Method
Sanyuan-World keeps the official HY-World 2.0 generative and reconstruction backbones frozen and adapts the pipeline at three points.
Hierarchical text conditioning (T0 / T1a).
T0 is the official unified English prompt used by the pilot script, containing no painting-specific information. T1a replaces scene descriptions with hierarchical ratio prompts: SAM3 six-class segmentation statistics are converted into layer_ratio (foreground / midground / background area ratio) and cls_ratio (mountain-rock, tree, water, building, person, cloud-fog proportions), then templated into a prompt. T1a is chosen because it can be generated automatically from sam3_summary.json for all 15 main-table paintings; the scene-description variant is kept only as side evidence.
Three-Distance camera trajectory (WorldNav).
The official trajectory candidate set is replaced by candidates based on the Chinese landscape painting principle of gaoyuan (high distance), shenyuan (deep distance), and pingyuan (level distance). schemeA is the formal B1 setting: gaoyuan θ = -60, shenyuan bf = 0.4 and θ = -20, pingyuan lr = 0.3 and θ = 0. A new --only_far filter enables single-distance controls, and five parameter overrides are exposed for sweeps. After the trajectory stage, make_three_distance_log.py writes three_distance_routes.json; this file is the gate and alignment source for later stages.
LOP-based post-hoc quality gating.
Quality gating is a post-hoc frame filter, not an online interceptor. gate_score_compose.py computes the S_LOP-based score and threshold, and gate_skipmap.py maps the result into a {view-traj: [idx]} skip list. The number of removed frames must be consistent with the statistics in lop_scores_a.json under θ. pano-*.png follows a separate branch, does not read the skip list, and is not counted in the removal rate. Reconstruction then uses WorldMirror + gsplat with fixed 9,999 steps, downsample 0.5, SH degree 3, and SSIM weight 0.2.
